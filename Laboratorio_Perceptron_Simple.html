7 El modelo completo

Peso de cada variable
Como las variables están estandarizadas, el tamaño del peso se puede comparar: entre más largo, más influye.
Cómo se estandarizó cada variable

La media y la desviación salen solo del entrenamiento. A cada valor se le resta la media y se divide por la desviación: x' = (x − media) / desviación.
